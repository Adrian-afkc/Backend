# AGENTS.md

FastAPI backend for ProyectoEF. The Angular frontend lives in the sibling directory `../Frontend`.

## Setup and run

- Python **3.15** is pinned (`.python-version`, `requires-python >=3.15`). Use `uv` from this directory; do not use bare `python`/`pip` or install a different interpreter.
- Install dependencies: `uv sync`
- Dev server: `uv run uvicorn backend.main:app --reload` (port 8000 by default)
- Copy `.env.example` to `.env` before running (it is gitignored). The backend reads `DB_*` and `JWT_*` variables from it at import time.
- Seed demo data: `uv run python seed.py` (idempotent; creates catalogs, 3 insumos, and the demo user `admin / Admin2026` with Argon2 hash).
- Smoke check: `curl http://127.0.0.1:8000/api/health/db` then `curl http://127.0.0.1:8000/api/insumo/` (note the trailing slash)
- Do **not** run `uv run backend` expecting a server: that script only prints a greeting (`src/backend/__init__.py`).

## Layout and conventions

- `src/backend/main.py` owns the `FastAPI` app and is the only place routers are registered: `app.include_router(rutaInsumo, prefix='/api')`. Router prefixes live in the API modules (`/insumo`), so routes end up as `/api/insumo/`.
- Layering: `apis/` = routers and endpoint wiring, `services/` = business logic, `schemas/` = Pydantic models, `db/` = data access, `config/` = `.env` loading. For a new resource, mirror the insumo trio (`insumo_api.py` with `rutaInsumo`, `InsumoService`, model in `schemas/`) and register the router in `main.py`.
- The codebase uses Spanish domain names and camelCase for functions, variables, and schema fields (`guardarInsumo`, `unidadMedida`, `stockMinimo`, `__mapear`). Follow the local style instead of PEP 8 renaming. Database column names stay snake_case (`id_insumo`, `stock_minimo`); the mapping happens in each service's `__mapear`.
- Endpoints are plain sync `def` and return Pydantic models directly; there are no `response_model`s or explicit status codes.
- There is no ORM. All persistence is raw parameterized SQL (`?` placeholders) through `src/backend/db/connection.py`; never f-string user input into a query.

## Database access

- SQL Server `OllaComunSector10` with **Windows authentication** (`Trusted_Connection=yes`, no user/password). Tables: `dbo.Categorias`, `dbo.UnidadesMedida`, `dbo.Insumos` (FKs `FK_Insumos_Categorias`, `FK_Insumos_Unidades`), `dbo.Usuarios`.
- `dbo.Usuarios` stores `Contrasena` as an Argon2 hash (salt included in the hash). Auth endpoints: `POST /api/auth/login` (public) and `GET /api/auth/me` (Bearer JWT). CRUD endpoints for insumos/categorías/unidades remain public by current product decision.
- `db/connection.py` exposes `consultar`, `consultarUno`, `ejecutar`, `insertar` and the `obtenerCursor()` context manager (commit on success, rollback on error, always closes). Open one connection per request: pyodbc connections are not thread-safe.
- `config/settings.py` loads `.env` with python-dotenv and builds the ODBC string. Driver 18 encrypts by default, so `TrustServerCertificate=yes` is required for the local instance.
- Domain errors live in `src/backend/errores.py` and are mapped by exception handlers in `main.py`: `ErrorDatoNoValido` → 400, `ErrorConflicto` (FK/unique violation, SQL error 547/2601/2627) → 409, `ErrorBaseDatos`/`pyodbc.Error` → 503. Missing rows return 404 via `HTTPException`.

## Current limitations (don't assume otherwise)

- **SQL Server is required** to serve any endpoint except the OpenAPI docs; without a reachable instance every call returns 503. Only Windows auth has been exercised locally.
- Ids are generated by `IDENTITY` columns, so POST bodies must not include them (`InsumoEntrada`, `CategoriaEntrada`, `UnidadMedidaEntrada`).
- There is no migration tool (no Alembic): the schema is maintained by hand in the existing database.
- CORS is configured for `localhost`/`127.0.0.1` on ports 4200 and 4000 only.
- JWT auth is stateless: logout is client-side token removal; stolen tokens remain valid until expiration. `JWT_SECRETO` must be set in `.env`.
- There is no test suite, linter, formatter, or CI config. If you add tests, add pytest as a dev dependency group via `uv add --dev pytest` and document the single-test command here.
